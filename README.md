# CS-250-Software-Development-Cycle

# How do I interpret user needs and implement them into a program? How does creating “user stories” help with this?
To Interpret user needs is to ask questions and receive detailed information on what the user is looking for.  Using the Scrum agile process, it’s easy to implement the user needs into a program.  The developer starts writing the code, and the Project Owner keeps the user in constant communication to ensure the requirements are implemented correctly.  User Stories lets the entire team know what details, code, and conditions will be implemented during that project.  

# How do I approach developing programs? What agile processes do I hope to incorporate into my future development work?
With the few programs I have developed, I would usually start coding the needs from the beginning and test as I implement more requirements into the program.  According to the Scrum agile process, I could have planned much better before starting this process.  I hope to utilize the Scrum agile process in future development.  I feel like it's one thing to learn, but implementing what you have learned makes everything come together.

# What does it mean to be a good team member in software development?
A good team member in software development includes multiple different characteristics.  My most important is respect.  Knowing how to give positive criticism or help without defending your team is crucial for morale and the group's commodity.  The second important characteristic is communication and collaboration.  Especially in an agile process, communication is critical.  From the transmission to the consumer to the tester, communication allows the team to stay on the same page and continue the same vision.
